\# Observatório Violência Contra a Mulher



Projeto de análise de dados e visualização em Power BI sobre a rede de enfrentamento à violência contra a mulher no Amazonas.



\## Tecnologias

\- Power BI

\- Python

\- Excel



\## Objetivo

Organizar e visualizar dados da rede de apoio à mulher em Manaus e interior do Amazonas.
